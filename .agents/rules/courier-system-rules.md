# Courier System - Global Rules

* **Architecture:** The frontend must be developed using Svelte, and the backend must be implemented using Spring Boot.
* **Performance Constraints:** The application interface must load within 3 seconds when under a concurrent load of 2 users.
* **Data Synchronization:** Any package status changes must be visible to users within a maximum of 1 minute after the change occurs.
* **Security & Data Privacy:** Data visible to Couriers, Workers, or Admins must never be accessible to standard Client users.
* **User Experience:** The user interface must be intuitive, allowing users to fully utilize the system within 15 minutes of their first interaction.
